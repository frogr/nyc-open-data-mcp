Remote MCP server

NYC Open Data for your AI assistant

MCP (Model Context Protocol) is the open standard that lets AI apps like Claude and Cursor call outside tools. This server gives them read-only access to NYC Open Data: restaurant health grades, 311 complaints, and the rest of the city's 2,400+ public datasets. No API key needed.
